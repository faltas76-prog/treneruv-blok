Návod k aplikaci a nahrání na GitHub
  1. Logo klubu: klepněte na ikonu míče vlevo nahoře a vyberte obrázek (PNG, JPG, WebP, GIF nebo SVG do 2 MB). Klepnutím na logo jej můžete změnit nebo odstranit. Logo se ukládá v prohlížeči tohoto zařízení.
  2. Přidání hráče: klikněte na „Nový hráč“, vyplňte jméno, post, číslo dresu, hodnocení a případnou poznámku. Hráče můžete později upravit nebo odstranit.
  3. Tréninky: tlačítkem „Zapsat“ uložíte datum, název jednotky, zaměření a týmový poznatek.
  4. Poznámky: vpravo rychle přiřadíte poznámku týmu nebo hráči. V archivu níže si můžete všechny poznámky přečíst, vyhledat je a jednotlivě mazat.
  5. Ukládání: data se automaticky ukládají do paměti prohlížeče v telefonu, tabletu či počítači. Na jiném zařízení použijte „Export zálohy“ a „Import“; data se mezi zařízeními sama nesynchronizují. Zálohu si pravidelně stáhněte.
  6. GitHub Pages: uložte tento soubor jako index.html do kořenové složky GitHub repozitáře. V repozitáři otevřete Settings → Pages, jako zdroj zvolte nasazení z větve, vyberte main a složku /(root), potom uložte. Po zveřejnění otevřete nabídnutou adresu GitHub Pages.

Soukromí: data nejsou odesílána na server, ale zůstávají v prohlížeči. Pro přístup z jiného zařízení použijte export a import zálohy.
